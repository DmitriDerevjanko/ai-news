📘 About the System

AI SmartCam is a real-time computer vision system built with FastAPI, YOLOv8n, and OpenCV. It processes live or local video streams and performs:

  • 🧍 Object detection — identifying people, cars, and other visible entities in real time.
  • 🎯 Visual tracking — maintaining object positions across frames using ByteTrack.
  • 🖥️ Side-by-side comparison — original footage on the left, annotated version on the right.

Frames are processed through ffmpeg → OpenCV → FastAPI (MJPEG) for smooth, continuous streaming below.
