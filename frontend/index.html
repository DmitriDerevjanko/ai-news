🧠 AI SmartCam — Live Object Detection

Real-time visual detection from Times Square, New York City.

📘 About the System

AI SmartCam is a real-time computer vision system built with FastAPI, YOLOv8n, and OpenCV. It processes a live HD stream from EarthCam Times Square and performs:

  • 🧍 Object detection — identifying people, cars, and other visible entities in real time.
  • 🎯 Visual tracking — maintaining object positions across frames using ByteTrack.
  • 🖥️ On-screen visualization — all detections are rendered directly on the live video stream.

The current version focuses on accurate real-time detection and visualization. Future updates will introduce counting, speed estimation, and advanced scene analytics.

Streamed frames are processed through ffmpeg → OpenCV → FastAPI (MJPEG) for smooth real-time display below.
